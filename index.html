Automated CI/CD Workflow

Add this GitHub Action to your repo (`.github/workflows/render-drawio.yml`) to automatically compile `.drawio` files to `.png` images on push.

name: Render Draw.io Diagrams
on:
  push:
    paths:
      - '**/*.drawio'
jobs:
  drawio-render:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Repo
        uses: actions/checkout@v3
      - name: Render Draw.io Diagrams
        uses: rlespinasse/drawio-export-action@v2
        with:
          path: docs/
          format: png
      - name: Commit changes
        uses: stefanzweifel/git-auto-commit-action@v4
        with:
          commit_message: "docs: render drawio diagrams to png"
